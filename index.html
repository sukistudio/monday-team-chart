🔀 merge (เปรมเคาะ 2026-10-11)

  • Tide / Beam / Harbor merge เอง เมื่อ QA PASS + review (Finance: Lantern PASS) — ยังต้องผ่าน PR ห้าม push main
  • เปรม approve เฉพาะ repo สำคัญ (production / เงิน / ข้อมูลลูกค้า / auth) และทุกโพสต์สาธารณะ
  • repo ข้อมูลการเงิน = repo สำคัญตัวแรก (2026-10-12): เปรม merge เองเฉพาะ PR แก้กฎผังบัญชี/จัดหมวด · รายงานประจำเดือน Harbor merge ได้
  • เปรมเห็นทุก PR แต่ไม่ต้องกด
